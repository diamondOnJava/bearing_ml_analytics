## Анализ бенчмарка и построение классификатора для диагностики состояния асинхронных электродвигателей

Пайплайн для baseline-модели классификации состояния подшипника по амплитудным значениям токов фаз и вибраций на характерных частотах.

Пайплайн спроектирован как воспроизведение эксперимента на бенчмарке из [статьи](https://mb.uni-paderborn.de/fileadmin-mb/kat/PDF/Veroeffentlichungen/20160703_PHME16_CM_bearing.pdf). 

### Текущие резултаты
#### 16.10.2026

На данный момент обучены и протестированы две модели: catboost и полносвязная нейронная сеть с оптимизацией на optuna.

Результаты сведены в confusion matrix в конце ноутбуков, точность наилучшего классификатора (FNN на спектральном анализе токов и временных статистиках) составила 66,1%. CatBoost справился чуть хуже (62,3%).

### Области для улучшения

Нужно пересмотреть подход к обработке датасета, особенно в месте перехода с временной области в частотную. Как вариант, можно добавить амплитуды сигналов не только для рассмотренных в [статье](dx.doi.org/10.1016/j.ymssp.2010.07.017) повреждений.

### Датасет

Структура matlab-файла:

N09_M07_F10_K001_1
- Info
    - RevisionMajor
    - RevisionMinor
    - MeasurementID

Временные метки семплов сигнала (признак `time_s`):
- X[0] (Mech_4kHz) - физические параметры, в обучении не использованы
- X[1] (HostService) - основной датасет, предобрабатывается отдельной функцией
- X[2] (Temp_1Hz) - измерения температуры подшипников и помещения

Замерямые в экспериментах сигналы:
- Y
    - force - радиальная сила
    - phase_current_1 - ток фазы A
    - phase_current_2 - ток фазы B
    - speed - скорость вращения ротора
    - temp_2_bearing_module - температура подшипника
    - torque - крутящий момент
    - vibration_1 - вибрация

Прочая метаинформация:
- Description
- General
- Recording
- Measurement
