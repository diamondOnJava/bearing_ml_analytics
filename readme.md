## Анализ бенчмарка и построение классификатора для диагностики состояния асинхронных электродвигателей

Пайплайн для модели классификации состояния подшипника по амплитудным значениям токов фаз и вибраций на характерных частотах.
Модель переводит сигналы токов и вибраций из временной области в частотную (используются знания ЦОС, в т.ч. преобразование Фурье и сигнатурный анализ токов).
На характерных разным неисправностям (несоосность ротора, ассиметрия, канавки, повреждения кольца и т.д.) подшипников частотах модель ищет аномалии и классифицирует подшипник: исправный, повреждения внутреннего кольца, повреждения внешнего кольца).

Пайплайн спроектирован как воспроизведение эксперимента на бенчмарке из [статьи](https://mb.uni-paderborn.de/fileadmin-mb/kat/PDF/Veroeffentlichungen/20160703_PHME16_CM_bearing.pdf). 
История отказов в датасете отсутствует.

### Текущие резултаты
#### 19.11.2026

На данный момент обучены и протестированы две модели: catboost, полносвязная нейронная сеть с оптимизацией на optuna.
В текущей версии также обучена XGBoost, добавлена обработка пропусков и исправлены ошибки с разделением выборки на трейн/тест.

Результаты сведены в confusion matrix в конце ноутбуков.
Лучше всех себя показали CatBoost (accuracy = 62.3%) и XGBoost (accuracy = 88,1%).

### Области для улучшения

Нужно пересмотреть подход к обработке датасета, особенно в месте перехода с временной области в частотную. Как вариант, можно добавить амплитуды сигналов не только для рассмотренных в [статье](dx.doi.org/10.1016/j.ymssp.2010.07.017) повреждений.

### Датасет

Структура matlab-файла:

N09_M07_F10_K001_1
- Info
    - RevisionMajor
    - RevisionMinor
    - MeasurementID

Временные метки семплов сигнала (признак `time_s`):
- X[0] (Mech_4kHz) - физические параметры, в обучении не использованы
- X[1] (HostService) - основной датасет, предобрабатывается отдельной функцией
- X[2] (Temp_1Hz) - измерения температуры подшипников и помещения

Замерямые в экспериментах сигналы:
- Y
    - force - радиальная сила
    - phase_current_1 - ток фазы A
    - phase_current_2 - ток фазы B
    - speed - скорость вращения ротора
    - temp_2_bearing_module - температура подшипника
    - torque - крутящий момент
    - vibration_1 - вибрация

Прочая метаинформация:
- Description
- General
- Recording
- Measurement
